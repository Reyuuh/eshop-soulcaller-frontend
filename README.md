# E-Shop SoulCaller - Frontend
## 📋 Project Overview

A modern e-commerce frontend built with React, featuring product browsing, shopping cart functionality, user authentication, and secure Stripe payment integration.

---

## ✨ Current Features

- ✅ **Product Catalog** - Browse and view products by category
- ✅ **Shopping Cart** - Add/remove items with Redux state management
- ✅ **User Authentication** - Login and registration system
- ✅ **Payment Integration** - Secure checkout with Stripe
- ✅ **Admin Dashboard** - Manage products, categories, and orders
- ✅ **Responsive Design** - Mobile-friendly interface
- ✅ **Order Tracking** - Thank you page for completed purchases
